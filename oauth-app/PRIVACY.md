# Privacy Policy - Pokati Gemini Notebook

Last updated: 2026-11-15

"Pokati Gemini Notebook" is a personal, single-user application operated by its owner for the owner's own use only. It is not distributed to, or offered to, any third party.

## Data accessed

With the owner's explicit consent, the application accesses the owner's own Gemini Notebook (formerly NotebookLM) notebooks and sources through Google's official Gemini Notebook API, using the scope `https://www.googleapis.com/auth/notebook`. It can list, create and rename notebooks and list and add sources, within the owner's own account.

## Data storage

OAuth tokens are stored only on the owner's own virtual machine, in the standard Google Cloud credential location, protected with file permissions 0600. No notebook content or token is sent to, stored on, or shared with any third-party server. The application makes calls only to Google APIs (notebook.googleapis.com, oauth2.googleapis.com, accounts.google.com).

## No sale, no sharing, no analytics

The application does not sell personal data, does not share personal data with third parties, and contains no advertising or analytics.

## Revoking access

The owner can revoke the application's access at any time from the Google Account permissions page: https://myaccount.google.com/permissions
