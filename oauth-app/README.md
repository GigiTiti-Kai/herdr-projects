# Pokati Gemini Notebook

A personal, single-user application operated by its owner for the owner's own use only. It is not distributed to, or offered to, any third party.

The application accesses the owner's own Gemini Notebook (formerly NotebookLM) notebooks and sources through Google's official Gemini Notebook API, using the OAuth client created in the owner's own Google Cloud project `pokati-gemini-notebook`. It is used to list, create and rename notebooks and to list and add sources, within the owner's own account, from the owner's own assistant environment.
